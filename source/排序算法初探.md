## 前言
排序算法是计算机算法中广泛应用的一类算法，关于该类算法的研究繁多复杂，究其原因在于对某种对象排序是人类日常活动中常见的行为，不论是学生成绩、销售业绩亦或是租房价格等等数不胜数。而采取某种方式对一组对象进行排序对人类来说并非难事，强大的视觉处理能力、记忆能力及大脑的运算能力，能够方便的对一组数据进行排序，但是排序的对象数目越大，人类的排序所花费的精力就越多，而计算机实现的排序算法可以很好的帮助人类，即使是简单的选择排序，计算机所花费的时间也远远小于人类，更不要提更加优美的归并排序及快速排序算法能极大降低排序时间，提高效率，更好的解放人类。

### 选择排序算法
```
# 选择排序
def selectsort(nums):
    for i in range(len(nums)):
        j = i
        minval = inf
        minidx = j
        while j < len(nums):
            if nums[j] < minval:
                minval = nums[j]
                minidx = j
            j = j + 1
            nums[i], nums[minidx] = nums[minidx], nums[i]
        return nums
```
